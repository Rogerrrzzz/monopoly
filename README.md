# Монополия

Курсовая работа по ООП. Консольная пошаговая экономическая игра для 2-4 игроков по мотивам "Монополии". Реализована на двух языках — **C++** и **Java**.

## Суть игры
 
Игроки ходят по полю из 12-16 клеток, покупают участки, платят аренду, строят дома при монополии на цвет, тянут карты "Шанс/Казна" или платят налоги. Побеждает последний игрок с положительным балансом.

## C++: сборка и запуск в Visual Studio

Требуются Windows и Visual Studio 2022 с рабочей нагрузкой **«Разработка классических приложений на C++»**. Для сборки выберите **C++20**.

1. Склонируйте репозиторий или скачайте его как ZIP и распакуйте.
2. В Visual Studio выберите **Создать проект → Пустой проект (C++)**. Файлы решения и проекта создаются локально.
3. В **Обозревателе решений** нажмите правой кнопкой на проект и выберите **Добавить → Существующий элемент**. Добавьте все файлы `.cpp` и `.hpp` из папки `cpp/`.
4. Выберите **Сборка → Собрать решение** (`Ctrl+Shift+B`). Для запуска без отладки нажмите **Ctrl+F5**. Окно консоли останется открытым после завершения программы.

## Java: сборка и запуск

Требуется JDK 17 или новее. Команды `javac` и `java` должны быть доступны в терминале.

Из корня проекта выполните:

```bash
cd java
javac -encoding UTF-8 -d out src/*.java
java "-Dfile.encoding=UTF-8" "-Dstdout.encoding=UTF-8" -cp out Main
```

Исходники находятся в `java/src/`, результаты компиляции — в `java/out/`.

IntelliJ IDEA можно использовать для написания кода. По требованиям лабораторной сборка и запуск выполняются из командной строки.
