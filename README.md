# Монополия

Курсовая работа по ООП. Консольная пошаговая экономическая игра для 2-4 игроков по мотивам "Монополии". Реализована на двух языках — **C++** и **Java**.

## Суть игры
 
Игроки ходят по полю из 12-16 клеток, покупают участки, платят аренду, строят дома при монополии на цвет, тянут карты "Шанс/Казна" или платят налоги. Побеждает последний игрок с положительным балансом.

## Лабораторная работа 2 (C++)
 
В этой части реализованы три класса предметной области и демонстрационная программа. Она показывает
композицию, агрегацию, проверку правил игры и разницу во времени жизни объектов.

## Сборка проекта
 
Требуется Windows и Visual Studio с компонентом «Разработка классических приложений на C++».
Файлов проекта Visual Studio в репозитории нет, поэтому проект создаётся вручную.
 
1. Склонируйте репозиторий или скачайте его как ZIP и распакуйте.
2. В Visual Studio выберите **Создать проект** → **Пустой проект** (C++).
3. Добавьте в проект все файлы `.hpp` и `.cpp` из репозитория:
   правый клик по проекту → **Добавить** → **Существующий элемент**.
4. Включите стандарт C++17: правый клик по проекту → **Свойства** → **C/C++** → **Язык** →
   **Стандарт языка C++** → **ISO C++17 Standard (/std:c++17)**.
   Конфигурацию и платформу выберите «Все».
5. Соберите проект: **Сборка** → **Собрать решение** (Ctrl+Shift+B).

## Запуск

Нажмите **Ctrl+F5** (запуск без отладки), чтобы окно консоли не закрылось сразу после завершения программы
